# ADR 0026: customer accounts and subscription implementation

Status: Superseded.

Use [ADR 0047](0047-single-organisation.md) for organisation ownership,
[ADR 0048](0048-unified-organisation-files.md) for file ownership and quota admission,
and [ADR 0020](0020-saas-billing-providers.md) for payment and billing boundaries. The
