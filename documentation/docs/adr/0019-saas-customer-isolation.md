# ADR 0019: personal and multi-organisation SaaS accounts

Status: Superseded by [ADR 0047](0047-single-organisation.md).

The platform no longer supports personal customer accounts, organisation membership,
tenant selection, or multiple organisations in one deployment. Agents must use ADR 0047
for ownership and authorization, ADR 0048 for shared files, and ADR 0020 for billing.
