# ADR 0021: user file library and storage quotas

Status: Superseded by [ADR 0048](0048-unified-organisation-files.md) and
[ADR 0051](0051-platform-core-and-file-library.md).

Personal file ownership, per-user quotas, and administrative user-library access are no
longer current. Agents must use ADR 0048 for the organisation-wide library and quota
model, ADR 0029 for folder/sharing behavior, and ADR 0051 for the distinction between
core storage and the optional File Storage presentation module.
